# Website Creation Agency Website

This is a ready-to-use Next.js App Router + Tailwind CSS website for Lub Run Enterprises website creation services.

## What is included

- Modern digital-agency homepage
- Services section
- Why work with us section
- Website creation process
- Portfolio showcase placeholders
- Website packages
- Detailed client project request form
- WhatsApp form submission to: https://wa.me/255689824682
- FAQ
- Final CTA
- Footer with email and WhatsApp details

## How to use

1. Extract this folder.
2. Open the folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local website URL shown in the terminal.

## Main file to edit

Most content is inside:

```bash
app/page.tsx
```

Edit these arrays near the top of the file:

- `services`
- `values`
- `process`
- `portfolio`
- `packages`
- `faqs`

## Build command

```bash
npm run build
```
